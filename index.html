How it works

One toolbar click or a keyboard shortcut. No filter syntax, no account, no setup.

🧹

Click → gone

Hides sticky & fixed bars and any overlay covering most of the viewport — and unlocks scrolling that pages lock behind modals.

↩️

Reversible undo

Click again to undo — no page reload. Destick records exactly what it changed and restores only that, never your interactions.

📌

Per-site memory

Clean a site once and it stays clean on your next visits, automatically. Turn auto-clean off per site whenever you want.

🟢

ON / OFF badge

The toolbar icon tells you at a glance whether Destick is active here, and how many things it hid on this page.

🎯

Element picker

For stubborn junk, press Alt+Shift+P and point at the element. No CSS selectors to learn.

⌨️

Shortcuts + late junk

Alt+Shift+X cleans or undoes. A watcher re-hides modals and overlays that appear after the page loads.

It never phones home

Most "cleaner" extensions ask for the keys to your whole browsing life. Destick asks for nothing.

  • ✓ No outbound request. No data sent anywhere. Destick initiates zero network traffic — and that claim is enforced in CI with a real runtime check.
  • ✓ No account, no sync. Your per-site choices and picked elements live only on this device, in local storage.
  • ✓ Only the "storage" permission. It runs on page load so it can hide junk before you see it — but it never sends anything out.
  • ✓ Auditable. The whole extension is open source under MIT. Read every line, or build it yourself.

Free, forever, and open

Honest answers

Including what Destick does not do — because that's how you know the rest is true.

Is it really 100% local?
Yes. Destick makes no outbound request and transmits no data anywhere. Your choices live only on your device in chrome.storage.local — no account, no .sync. The "no network" claim is checked in CI with a positive control that proves the monitor actually catches a request.
Can I undo it if it hides too much?
Yes — that's the whole point. Click the icon again or press Alt+Shift+X to undo, with no reload. Destick is aggressive by design, so it can occasionally hide a legitimate nav bar; undo, the element picker, or turning off auto-clean for that site are the corrections.
Does it block ads or give cookie consent for me?
No. Destick is not an ad blocker and it doesn't answer consent prompts for you. It removes the layout junk — sticky bars, modals, overlays — and gives you back scrolling. Hiding an element stops it blocking your clicks, but doesn't stop its scripts or network.
What can't it clean (yet)?
This MVP works on the top document, open shadow roots, and <iframe> elements used as overlays. It does not clean inside iframes, closed shadow roots are handled at host level only, native <dialog> modals may stay inert behind the scenes, and SPA route changes with no DOM mutation aren't caught. Firefox isn't supported yet.
How do I install it today?
The Chrome Web Store listing is coming soon. For now you can install it unpacked: clone the repo, run npm install && npm run build, then load the dist/ folder at chrome://extensions with Developer mode on. Full steps are in the GitHub README.
