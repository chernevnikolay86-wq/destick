Destick

One click hides sticky/fixed/overlay junk and restores scrolling. 100% local — no account, no network, no tracking.

Pick an element to hide

Open a normal web page, then pick the stubborn element. It is hidden now and remembered for that site.

Sites

No per-site settings yet. Clean a page or add one below.

Keyboard shortcuts

Toggle clean / undo: Alt+Shift+X  ·  Pick element: Alt+Shift+P

Unassigned or want to change them? Open chrome://extensions/shortcuts (copy & paste into the address bar).

Privacy

Destick does not initiate any outbound request or send any data anywhere. Everything (your per-site choices and picked elements) stays on this device in local extension storage. The content script has broad page access because it must run on load to hide junk before you see it — but it never transmits anything.

Hiding an element removes it visually and stops it intercepting clicks/focus. It does not stop that element's scripts/network and does not record cookie consent for you.
